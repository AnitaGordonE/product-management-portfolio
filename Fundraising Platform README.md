# Community Gifting & Fundraising Platform

## 1. Project Overview

This case study explores the product strategy and development of a digital platform designed to simplify community gifting, group contributions and fundraising.

**Role:** Product Manager  
**Project Type:** Digital Product  
**Focus:** Product Strategy, User Research, Requirements Documentation and Feature Prioritisation.

## 2. Problem Statement

Coordinating group gifts and community contributions can be challenging. Users often rely on multiple communication channels and manual processes, making it difficult to track contributions, share information and manage fundraising activities.

## 3. Proposed Solution

A centralised mobile platform that enables users to:
- Create and manage communities.
- Create and share gift wishlists.
- Organise group contributions.
- Launch fundraising campaigns.
- Share photos and updates.
- Communicate within their communities.

## 4. Target Users

- Families and friends.
- Community groups.
- Event organisers.
- Fundraising organisers.
- Individuals coordinating group contributions.

## 5. Key Product Features

| Feature | Purpose | Priority |
|---|---|---|
| User Registration | Create and manage accounts | High |
| Community Creation | Build and manage groups | High |
| Wishlists | Share gift preferences | High |
| Donations | Coordinate contributions | High |
| Fundraising | Raise money for specific causes | High |
| Photo Sharing | Share memories and updates | Medium |
| Community Messaging | Improve communication | Medium |

## 6. Product Requirements

Each feature would have defined requirements, user stories and acceptance criteria before development.

**Example User Story:**

As a user, I want to create and share a wishlist so that friends and family can easily see the gifts I would appreciate.

**Acceptance Criteria:**
- Users can create a wishlist.
- Users can add and remove items.
- Users can share their wishlist.
- Other users can view the shared wishlist.

## 7. Product Roadmap

**Phase 1 – Foundation**
- User registration and onboarding.
- Community creation.
- User profiles.

**Phase 2 – Core Features**
- Wishlist creation.
- Group contributions.
- Fundraising functionality.

**Phase 3 – Engagement**
- Community messaging.
- Photo sharing.
- Notifications and engagement improvements.

## 8. Success Metrics

The product's performance would be evaluated using:
- User registration and activation rates.
- Monthly active users.
- Number of communities created.
- Wishlist creation and engagement.
- Fundraising campaign participation.
- User retention rates.

## 9. Key Learnings

This case study demonstrates how product strategy, user needs, feature prioritisation and structured requirements documentation can translate a business problem into a practical digital product solution.
